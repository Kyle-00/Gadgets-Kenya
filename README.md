# Gadgets Kenya - E-Commerce Product Showcase

## Project Overview

Gadgets Kenya is a responsive e-commerce electronics website built using HTML and CSS. The website showcases premium gadgets and modern UI/UX principles including responsive layouts, CSS Grid, dark mode support, and interactive product cards.

---

# Features

- Responsive product showcase
- CSS Grid product layout
- Product hover effects and animations
- Shopping cart sidebar
- Filter and sort UI section
- Responsive product cards
- Typography hierarchy
- Accessible color contrast
- Mobile responsive design
- Dark mode support
- CSS custom properties
- Sticky navigation
- Print stylesheet

---

# Technologies Used

- CSS
- Font Awesome Icons
